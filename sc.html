01 • Introduction

What is Conditional Formatting?

Conditional Formatting is an Excel feature that automatically changes the appearance of a cell when its value satisfies a particular condition.

Data
→
Condition
→
Format

For example, if salary is greater than ₹80,000, Excel can automatically make that cell green.

⚡

Simple Definition

Conditional Formatting means: "Apply formatting automatically when a condition is true."

Salary > ₹80,000 GREEN
Definition 02 / 12
02 • Importance

Why do we use it?

Large Excel datasets can contain thousands of values. Conditional Formatting helps us understand important information quickly.

👀

Easy Visualization

Numbers become easier to understand because colors and symbols show important values immediately.

🚨

Find Problems

Low sales, high expenses, duplicate values and abnormal records can be highlighted.

⚡

Save Time

Instead of manually checking each row, Excel automatically applies the rule.

05 • Step by Step

How to Apply Conditional Formatting

1. Select Data
→
2. Home
→
3. Conditional Formatting
→
4. Choose Rule
→
5. Format

Example: Salary > ₹80,000

  1. Select the Salary column.
  2. Open the Home tab.
  3. Click Conditional Formatting.
  4. Select Highlight Cells Rules.
  5. Choose Greater Than.
  6. Enter 80000.
  7. Choose Green formatting.
✓

Final Result

Every salary greater than ₹80,000 is automatically highlighted.

No need to manually color every cell.

09 • Custom Rules

Custom Formula Rules

Excel also allows us to create custom conditional formatting using formulas.

Example

Suppose we want to highlight employees whose salary is greater than ₹80,000.

Formula =A2>80000

The formula checks each row and formats the row when the condition is TRUE.

Logic

Cell Value
→
Condition
→
TRUE
→
Format

Custom formulas are useful when simple built-in rules are not enough.
